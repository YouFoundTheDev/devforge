# DevForge Portal

The DevForge portal is the Backstage frontend for software discovery,
self-service service creation, technical documentation, and service health.

## Platform capabilities

- Browse services, owners, APIs, resources, and dependency relationships in the
  Software Catalog.
- Create a TypeScript service with the **Create Production Service** template.
- Review deterministic CI, deployment, security, and documentation signals on
  service entity pages.

## Local development

Start the portal from the repository root with `yarn start`. The local catalog
and provider fixtures require no GitHub credentials. Optional GitHub publishing
uses backend-only configuration documented in the project README.

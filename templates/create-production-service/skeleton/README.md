# DevForge Service

A production-oriented Node.js and TypeScript service scaffold generated by the
DevForge Golden Path.

## Run locally

```sh
npm install
npm run dev
```

The service exposes `GET /health` on port 3000. Set `PORT` to use another port.

## Quality checks

```sh
npm run lint
npm run typecheck
npm test
npm run build
docker build -t devforge-service .
```

The GitHub Actions workflow also runs `npm audit` and scans the built container
with Trivy.
